## 1. Цель проекта

Сервис автоматически принимает текст клиентской заявки, отправляет её в **Grok 4.20** через **RouterAI**, извлекает сущности и возвращает структурированную карточку лида в формате JSON.

Основной фокус — качество промптов, защита от галлюцинаций, обработка неполных и противоречивых данных, строгая валидация и автоматическое тестирование.

## 4. Пошаговая установка (с нуля)

### Шаг 1. Установите Python

1. Скачайте Python с официального сайта: https://www.python.org/downloads/
2. При установке **обязательно** поставьте галочку **Add Python to PATH**
3. Проверьте в терминале:
   ```bash
   python --version
   ```
   Должно показать версию 3.10 или выше.

### Шаг 2. Откройте папку проекта

Перейдите в папку `ai-lead-classifier` и откройте терминал прямо в ней.

### Шаг 3. Создайте виртуальное окружение

```bash
python -m venv .venv
```

### Шаг 4. Активируйте окружение

**Windows:**
```bash
.venv\Scripts\activate
```

**Mac / Linux:**
```bash
source .venv/bin/activate
```

После активации в начале строки появится `(.venv)`.

### Шаг 5. Установите зависимости

```bash
pip install -r requirements.txt
```

### Шаг 6. Настройте API-ключ

1. Скопируйте файл:
   ```bash
   cp .env.example .env
   ```

2. Откройте файл `.env` любым текстовым редактором.

3. Найдите строку:
   ```env
   ROUTERAI_API_KEY=your_routerai_api_key_here
   ```

4. Замените `your_routerai_api_key_here` на ключ, который дал преподаватель.

5. Сохраните файл.

> Важно: файл `.env` уже добавлен в `.gitignore`. Ключ никогда не попадёт в GitHub.

### Шаг 7. Запустите сервис

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Вы должны увидеть сообщение:
```
Uvicorn running on http://127.0.0.1:8000
```

Откройте в браузере: **http://127.0.0.1:8000/docs**

Пример итогового отчёта соответствует формату из ТЗ §13.

## 8. Основные технические решения (почему это надёжно)

1. **Двойная валидация**  
   Сначала `jsonschema`, потом Pydantic. Даже если модель немного «поплывёт», сервис не пропустит плохой ответ.

2. **Строгий системный промпт**  
   Все 16 правил из раздела 8 ТЗ прописаны явно. Модель знает, что нельзя выдумывать данные.

3. **Низкая temperature (0.2)**  
   Повышает стабильность и повторяемость ответов.

4. **Автоматический retry**  
   Если ответ невалидный — сервис делает ещё одну попытку.

5. **Полное логирование**  
   Каждый запрос сохраняется со всеми полями, требуемыми в ТЗ, без секретов.

6. **Обработка всех ошибок**  
   Auth, Rate Limit, Timeout, Unavailable, Invalid JSON, Validation Failed, Internal Error.

7. **28 тестовых кейсов**  
   Покрыты все обязательные категории + дополнительные сложные случаи.

## 10. Что делать, если что-то не работает

| Проблема                          | Решение |
|-----------------------------------|--------|
| `ModuleNotFoundError`             | Активируйте `.venv` и выполните `pip install -r requirements.txt` |
| Ошибка авторизации RouterAI       | Проверьте, правильно ли скопирован ключ в `.env` |
| Порт 8000 занят                   | Запустите на другом порту: `--port 8001` |
| Тесты падают                      | Убедитесь, что сервер не обязателен — runner вызывает логику напрямую |
